# Meteor Arena

Арена-шутер сверху вниз, сделан на Unity 6. Играешь за пилота, который держит оборону против волн врагов пока с неба падают метеориты.

## Геймплей

Арена генерируется процедурно каждый раз заново — никаких загрузок из файлов, всё строится кодом при старте. Враги идут волнами, с каждой волной их становится больше и появляются новые типы. Между волнами короткая пауза чтобы выдохнуть.

Три типа врагов:
- **Stalker** — быстрый, лезет в ближний бой
- **Brute** — толстый, медленный, много хп
- **Swarm** — маленький, появляется роями, с 4-й волны некоторые могут стрелять

## Управление

| Кнопка | Действие |
|--------|---------|
| WASD | Движение |
| Space | Прыжок |
| ЛКМ (удержание) | Стрельба |
| ПКМ | Метеоритный удар (нужно навести на точку) |
| Shift | Рывок |
| Q | Щит (снижает входящий урон) |
| E | Ускорение |
| F | Замедляющая зона |
| V | Переключить вид (сверху / от первого лица) |

## Способности

**Метеоритный удар (ПКМ)** — самая мощная штука. Жмёшь, кружок предупреждает где упадёт, через секунду прилетает метеор. Кулдаун 4 секунды, но когда попадает по толпе — убивает всё в радиусе.

**Рывок (Shift)** — короткий быстрый бросок в сторону куда идёшь. Хорошо уходить от группы или от снарядов дальних врагов.

**Щит (Q)** — 2 секунды получаешь 55% меньше урона. Удобно когда тебя окружили.

**Ускорение (E)** — ненадолго быстрее бегаешь и стреляешь чаще.

**Замедление (F)** — ставишь зону под ногами, враги в ней тормозят в 2.5 раза.

## Запуск

Открыть проект в Unity 6000.0.4f1, нажать Play. Билд через File → Build Settings → Build.

Сложность выбирается в меню: Easy / Normal / Hard — влияет на количество врагов в волне.

## Технически

Весь визуал (арена, материалы, свет) и звук генерируются в рантайме кодом — никаких ассетов в проекте кроме префабов врагов. Звуки выстрела и взрыва сделаны через FM-синтез прямо в C#.
